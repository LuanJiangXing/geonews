## 设计说明

- **结构**：`GEO + [信号标] + EWS`，信号标替代字母 N
- **字体**：URW Bookman Demi（衬线宽体，开源）
- **配色**：Ember `#E63A1F` / Ember Deep `#A8210B` / Ink `#17120F` /
  Paper `#F4EFE8` / Night `#1B2430` / Mute `#8C8178`
- **小尺寸优化**：① 砍掉留白 ② 描边加粗（让 1.5px 的虚笔画变成 2.5px 实笔画）

### 80px 宽实测

| 版本 | 尺寸 | 模糊占比 |
|---|---|---|
| 优化前 | 80×12 | 53.9% |
| **定稿** | **80×17** | **38.0%** |

字高 +42%，着墨像素 +91%。

### ⚠️ 大尺寸不要直接用定稿参数

定稿的 `condense 0.68` + `embolden 4.5` + `track 0.005` 都是为 80px 小水印优化的，
放到大画面会又粗又挤。大尺寸改用 **Light 字重 / condense 0.88 / embolden 0 /
track 0.08**，并且**按字高定尺寸**而不是按宽度（压扁版宽高比只有 5.30，放开是 7.35+）。
片头词标就走的这套，见 `intro/wordmark_variants.py`。
