# 片尾生成器

把本期链接排成片尾。内容放得下时静止展示；超高时自动改为从下往上滚动。

**时长固定 15 秒**（除非用 `--duration` 显式指定秒数）。
链接少时不再缩短——多出来的时间摊到揭示过程里，让画面一直在动，
结尾再加一段整体淡出。

## 每期独立

链接文件与成片都放在**该期目录**下，生成器只是工具：

```
<期号>/
├── 05-片尾链接.md      ← 要改的只有这个
└── out/片尾.mp4

outro/                 ← 共用，不装任何一期的内容
├── build.py
└── assets/wordmark-c2.png
```

## 用法

```bash
cd outro
python3 build.py --links ../0930/05-片尾链接.md --out ../0930/out/片尾.mp4
```

可选：`--title`（页首标题，默认「本期链接」）、`--duration`（秒数，默认 15）。

## 链接文件格式

一行一条，两种写法都支持：

```
## 名义
https://...
```

或

```
名义  https://...
```

## 自动决定的事

- **要不要滚**：算出内容总高，超过可用高度才滚
- **链接字号**：能放下最长链接的前提下尽量大
- **揭示节奏**：内容偏少时整体拉长，摊满 15 秒

## 现行参数

| 项 | 值 |
|---|---|
| 画布 / 帧率 | 1920×1080 / 30fps |
| 底色 | 取自 `tools/palette.py` 的 `DARK`，随期轮换 |
| 收尾词标 | `assets/wordmark-c2.png`（Light 字重，与片头同版） |

改字号、间距都在 `build.py` 顶部常量区。
