# 成片拼装（build.py）

每期一份，从 `_project/build.py` 复制到 `<期号>/build.py` 后改 `SEGMENTS`。
字段含义写在脚本顶部注释里。

## 分两段跑

```bash
python3 build.py --full --only pass1   # 按裁剪点切片 → 放大 → 拼片头正片片尾
python3 build.py --full --only pass2   # 叠底栏/水印 → 各交界插转场 → 出成片
```

一次跑完 1080p 会超过单次调用时限、进程被杀、产出缺 moov atom 的残缺文件。

其他开关：`--draft`（1280×720 预览）、`--ticker`（烘焙底栏，默认不用）、
`--wm`（加回左上角水印，默认不加）、`--bar-only`（只出底栏叠加层）。

## 裁剪规则

**整段静音则不裁**；大部分有口播才按语音起止裁首尾。
判据是**口播覆盖率**（语音总时长 ÷ 片长，门槛 `NARRATION_COVER = 0.5`）。

素材音轨常常整条是静的，按旧逻辑"找语音起止"会把片子裁没
（实测 49.2s 被裁到 0.54s）。素材体检报的"有声"只代表有音轨。

## 转场不占时长

色带第 32 帧正好完全盖住画面，把这一帧对准切点，叠上去前后总长不变。
算成片时长只用 片头 + 正片 + 片尾。

## 会反复遇到的坑

| 坑 | 表现与对策 |
|---|---|
| 素材左右带黑边 | 录屏左右各约 62px（1280 宽下）。水印位置必须用**占输出尺寸的比例**，用固定像素会压在黑条上 |
| 片头片尾没有音轨 | 直接和有声正片 concat 会让音频整体错位，拼装前补等长静音轨（`ensure_audio()` 已处理） |
| `ImageDraw` 不做 alpha 混合 | 它把 RGBA 原样写进像素，`convert("RGB")` 丢 alpha 后带透明度的笔触全变满亮度——表现是"硬跳"不是淡入。绘制必须画在独立透明层再合成 |
| 渲染前不清帧目录 | 残留旧帧会被 ffmpeg 一起读进去，成片时长和内容都会错 |
| 改一段就想全重渲 | 改一段只重渲一段，pass1 有缓存会跳过未变段 |
| `--draft --full` 出的是 1080p，不是 720p | pass1 先接 1080p 的片头，`base` 被标成 1920×1080；转场序列是 1080p 的 PNG，叠到 720p 正片段上只取左上角一块，**词标跑到偏下**。已修：draft 时片头片尾与转场序列都缩到同尺寸。**验转场就看「词标 y 中位 ≈ 画面中心」** |
