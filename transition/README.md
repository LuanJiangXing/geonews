# 转场

新闻之间的过渡动画。**色带从左扫入 → 盖住上一条 → 停顿（logo 居中）→ 右移退出、露出下一条。**

## 在用的是两套

| 目录 | 用在哪 | 引用处 |
|---|---|---|
| `v3/` | 深色转场（交界有一侧偏深） | `build.py` 的 `DARK_SEQ` |
| `v5-暖米/` | 浅色转场（交界两侧都浅） | `build.py` 的 `LIGHT_SEQ` |

各出 72 帧 PNG 叠加序列（`叠加序列/转场_%04d.png`）。

**想看效果**：`v3/转场演示.mp4`（普通 MP4，双击可看）；
要看带透明的动图用 `转场叠加_预览.png`（APNG，Windows「照片」双击即可）。

## 时长

**2.4 秒**（72 帧 @30fps）：0–1.07s 扫入 ｜ 1.07–1.80s 停顿 ｜ 1.80–2.4s 退出。

**转场不占成片时长**——色带第 32 帧正好完全盖住画面，把这一帧对准切点，叠上去前后总长不变。

## ⚠️ 颜色不在这里，在 tools/palette.py

**别被目录名骗**：`v5-暖米` 是历史遗留的名字，它渲染的是 `palette.py` 里 `LIGHT` 当前指向的配色
（第 3 期是 **L1 品牌纸白**，不是暖米）。`v3` 同理，跟着 `DARK`（第 3 期是 P1 净黑）。

**换配色后必须重新生成叠加序列**，否则成片还是旧色：

```bash
python3 transition/v3/build.py        # 深色
python3 transition/v5-暖米/build.py   # 浅色
```

> 坑：生成脚本里 `sys.path` 引用 `HERE`，所以 **palette 的 import 必须放在 `HERE` 定义之后**，
> 否则报 `NameError: name 'HERE' is not defined`。

## 关键做法

色带**完全盖住画面的那一刻切换底层**——此时整屏被遮住，切换不可见，
所以退出时露出的自然就是下一条新闻。这也是它能当"转场"而不是"logo 动效"的原因。

改节奏、色带斜度、logo 大小都在各目录 `build.py` 顶部参数区。

## Logo 素材

停顿那一刻居中的 wordmark 在 `transition/logo/`：

| 文件 | 字形 | 配 | 给谁用 |
|---|---|---|---|
| `logo-dark.png` | 纸白 | 深色色带 | `v3` |
| `logo-light.png` | 墨黑 | 浅色色带 | `v5-暖米` |

两份都用 cairosvg 从 `logo/versions/★直接用这个/` 的两个定稿 SVG 光栅化（1760px 宽）。
**logo 定稿已锁定**——这里只是导出位图；要动 logo 先改定稿，再重出这两张。

> 2026-10-10：原先两个脚本引用 `transition/v1/build/logo-*.png`，而 `v1/` 在早前清理时被删了，
> 导致换配色后脚本报 `FileNotFoundError`。已改为指向 `transition/logo/`。
